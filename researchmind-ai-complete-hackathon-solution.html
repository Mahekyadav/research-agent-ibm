01  Project Name

"Where Knowledge Connects — Think Deeper, Research Faster, Discover More."

The name communicates depth of understanding (Mind), domain focus (Research), and intelligent amplification (AI). The tagline positions it as both a productivity tool and an intellectual partner.

02  Problem Understanding

Modern research is fragmented across arXiv, PubMed, IEEE Xplore, Semantic Scholar, institutional repositories, and personal note libraries. The core pains are:

  • Information overload — thousands of papers published daily; impossible to read manually.
  • Shallow summarization — existing tools summarize individually rather than synthesizing across sources.
  • Gap blindness — researchers miss white spaces in literature because no tool actively highlights them.
  • Disconnected toolchains — PDF readers, citation managers, note tools, and search engines are siloed.
  • No predictive intelligence — no tool forecasts where a research domain is heading.
  • Multimodal friction — graphs, tables, equations in PDFs cannot be queried conversationally.

03  Solution Overview

ResearchMind AI is a fully agentic, multimodal research intelligence platform. It combines eleven specialized AI agents orchestrated via IBM Langflow, powered by IBM Granite models, and deployed on IBM Cloud. A researcher can upload PDFs, paste URLs, write notes, or ask free-form questions, and the system returns a synthesized literature review, detected research gaps, trend predictions, knowledge graphs, and a ready-to-submit research proposal — all in one session.

04  Why This Solution is Innovative

  • True synthesis, not summaries — Granite compares and contrasts findings across papers to generate coherent narratives with contradictions highlighted.
  • Proactive gap detection — a dedicated agent maps the citation graph and semantic space to surface unexplored intersections.
  • Multimodal understanding — charts, tables, and equations are extracted and reasoned over, not ignored.
  • Agent memory & continuity — agents share a structured working memory (Redis + vector store), enabling multi-turn research sessions.
  • One-click outputs — from raw PDFs to a formatted literature review, bibliography, research proposal, and slide deck in one workflow.
  • IBM-native — fully built on IBM Cloud, Granite, and Langflow, making it enterprise-ready and auditable.

06  Multi-Agent Design

1. Query Understanding Agent

Input: Raw user query or question.
Output: Structured intent JSON: {topic, subtopics, time_range, modality, task_type}.
Tools: Granite 13B (intent classification), spaCy NER.
Role: Parses ambiguous queries into actionable parameters that drive all downstream agents. Detects whether the task is "find papers", "write review", "detect gaps", etc.

2. Academic Search Agent

Input: Structured intent from Agent 1.
Output: Ranked list of paper metadata (title, abstract, DOI, year, citations, authors).
Tools: arXiv API, Semantic Scholar API, PubMed Entrez, IEEE Xplore API, Crossref.
Role: Fan-out search across all academic sources, de-duplicate, and score relevance using Granite embeddings.

3. PDF Processing Agent

Input: PDF files (uploaded or fetched by URL).
Output: Structured document JSON: {sections, abstract, findings, methodology, limitations, future_work, equations, citations}.
Tools: PyMuPDF, pdfplumber, GROBID (section parser), Granite for semantic chunking.
Role: Deep structural extraction; chunks text into semantically meaningful passages for embedding.

4. OCR / Image Analysis Agent

Input: Images of charts, graphs, tables, equations from PDFs.
Output: Textual description + extracted data values + LaTeX equations.
Tools: Tesseract OCR, IBM Visual Recognition, Granite multimodal, pix2text (equation OCR).
Role: Makes visual content queryable. A bar chart becomes a data table; an equation image becomes LaTeX.

5. Literature Review Agent

Input: Structured extractions from Agent 3 + 4, top-k retrieved chunks from vector DB.
Output: Multi-section literature review: introduction, thematic synthesis, methodology comparison, contradictions, conclusions.
Tools: Granite 34B (synthesis), LangChain MapReduce, citation formatter (APA/IEEE/MLA).
Role: Core synthesis engine. Does not summarize papers sequentially — it identifies cross-paper themes and writes a coherent narrative.

6. Citation Validation Agent

Input: Extracted citations + DOIs from all processed papers.
Output: Validated BibTeX, broken link flags, retraction alerts, impact factor, H-index of authors.
Tools: Crossref API, Retraction Watch DB, OpenCitations, Unpaywall.
Role: Ensures academic integrity. Flags retracted, predatory, or unverifiable sources.

7. Research Gap Detection Agent

Input: Embeddings of all papers + citation graph + literature review.
Output: Ranked list of research gaps with justification, affected papers, and gap score.
Tools: Milvus nearest-neighbor analysis, Granite reasoning, citation graph topology (NetworkX).
Role: Finds semantic white spaces — topics that are cited as future work across many papers but have no papers yet. Also detects methodological gaps.

8. Trend Prediction Agent

Input: Citation counts over time, keyword frequency time series, topic cluster evolution.
Output: Trend forecast: {topic, trajectory: rising/falling/stable, predicted_peak_year, confidence}.
Tools: Prophet (time-series), Granite reasoning for qualitative trend narration, Semantic Scholar citation API.
Role: Predicts which research directions will dominate in 1–3 years.

9. Knowledge Graph Agent

Input: All extracted entities (concepts, methods, datasets, authors, institutions).
Output: Knowledge graph in JSON-LD: nodes (entities), edges (relationships like "uses", "improves", "contradicts").
Tools: spaCy + custom NER, Granite relation extraction, Neo4j (IBM Cloud), vis.js for rendering.
Role: Builds a navigable semantic map of the research domain.

10. Visualization Agent

Input: Knowledge graph, citation data, trend series, topic clusters, embeddings (UMAP-reduced).
Output: Interactive chart configs (D3.js/Recharts JSON) for: topic clusters, citation network, evolution timeline, trend lines, radar charts.
Tools: UMAP, D3.js, Recharts, Cytoscape.js.
Role: Translates data structures into human-readable, interactive visualizations served to the dashboard.

11. Report Generation Agent

Input: Literature review, gaps, trends, visualizations, citations, research proposal.
Output: Formatted PDF report, DOCX report, BibTeX bibliography, PowerPoint slide deck.
Tools: Granite 34B (proposal writing), python-docx, ReportLab, python-pptx.
Role: Final-mile agent that packages all insights into a publication-ready output.

Agent Communication Protocol

All agents communicate via structured JSON messages on a Redis pub/sub bus. Each message carries: agent_id, job_id, session_id, payload, and status. Langflow orchestrates the DAG — no agent calls another directly. The shared working memory (Redis Hash per session) stores intermediate results so any agent can read prior outputs without re-computation.

09  Features

Core Features

  • AI-Generated Literature Review — Multi-section, thematic, citation-rich narrative across dozens of papers.
  • Smart Citations — Inline citations auto-inserted with style selection (APA/IEEE/MLA/Chicago).
  • Automatic Bibliography — One-click BibTeX / RIS / Endnote export from the citation graph.
  • Research Roadmap — Visual timeline of a field's evolution + predicted next milestones.
  • Related Papers Recommendation — Semantic similarity + citation co-occurrence hybrid ranking.
  • Paper Similarity Score — Cosine similarity between any two papers' embeddings with explanation.
  • Semantic Search — Query in natural language: "papers that use transformers for drug discovery after 2021."
  • Citation Verification — CrossRef + Retraction Watch validation; flags broken, retracted, predatory links.
  • Contradiction Detection — Surfaces pairs of papers with conflicting claims, ranked by severity.
  • Novelty Score — Measures how semantically distant a paper is from existing literature; quantifies originality.
  • Future Work Prediction — Extracts "future work" sections from all papers; clusters them into prediction themes.
  • Automatic Research Proposal Generation — Gap + trend data fed into Granite to produce a full proposal draft.
  • Personalized Reading List — User interest profile built from session history; ranked daily recommendations.
  • Daily Research Updates — Cron job fetches new papers matching saved topics; email digest via IBM SendGrid.
  • AI Research Assistant Chatbot — RAG-based conversational agent over the user's personal corpus.

14  AI Workflow — Upload to Final Report

  1. User uploads PDF → stored in IBM COS; job queued in Redis.
  2. PDF Processing Agent extracts text, splits into sections, identifies figures/tables/equations. OCR Agent processes any embedded images.
  3. Granite embedding model encodes each chunk → vectors upserted into Milvus with paper_id metadata.
  4. Citation Validation Agent extracts references → verifies against Crossref → flags issues.
  5. User initiates "Generate Literature Review" → Query Understanding Agent parses scope.
  6. Milvus ANN search retrieves top-k chunks → augmented with PostgreSQL metadata.
  7. Granite 34B Literature Review Agent runs MapReduce: map = per-paper synthesis prompt; reduce = thematic synthesis prompt with cross-paper comparison instructions.
  8. Gap Detection Agent analyzes citation graph topology + semantic distance matrix → produces gap list.
  9. Trend Agent runs Prophet on citation time series → Granite narrates the forecast.
  10. Knowledge Graph Agent runs NER + relation extraction → writes to Neo4j.
  11. Visualization Agent generates D3 configs → streamed to frontend via WebSocket.
  12. Report Generation Agent assembles all outputs → Granite writes executive summary + proposal → python-docx/ReportLab renders final DOCX/PDF → uploaded to IBM COS → download link returned.

16  Scalability

  • IBM Code Engine auto-scales FastAPI and Celery workers to zero on idle; scales to hundreds of instances on load.
  • Milvus horizontal sharding supports billions of vectors; IBM Kubernetes Service manages node pools.
  • Celery + Redis task queue decouples heavy PDF processing from the request cycle.
  • Langflow pipelines are stateless and can run in parallel for different sessions.
  • PostgreSQL read replicas on IBM Databases for high-read workloads.
  • IBM COS is infinitely scalable for PDF/report storage with lifecycle policies.

17  Security

  • IBM App ID — OAuth 2.0 / OIDC authentication; JWT tokens verified on every API request.
  • Data isolation — all DB queries scoped by user_id; no cross-tenant data leakage.
  • IBM COS — server-side AES-256 encryption at rest; HTTPS in transit.
  • Secrets management — IBM Secrets Manager for all API keys (watsonx.ai, external APIs).
  • PII handling — author names/emails anonymized in logs; GDPR-compliant data deletion endpoints.
  • Rate limiting — per-user API rate limits enforced at the FastAPI gateway level.
  • Vulnerability scanning — IBM Container Registry scans all images before deployment.

26  UI Design

The UI is inspired by the clarity of Notion, the search-first UX of Perplexity, and the academic credibility of Google Scholar:

  • Layout: Fixed left sidebar (64px icon rail + expandable 240px nav) + main content area. No top navbar clutter.
  • Typography: Inter for UI, Lora for review text (academic feel), JetBrains Mono for code/equations.
  • Color system: White base (#ffffff), surface (#f7f8fa), IBM Blue (#0062ff) as primary action, Violet (#7c3aed) for AI-generated content indicators, semantic Red for contradictions, Green for validated citations.
  • AI transparency: Every AI-generated block has a subtle violet left border and "Generated by Granite" micro-label — building trust.
  • Progressive disclosure: Paper cards show title + 2-line abstract; expand inline to full extracted sections. No modal hell.
  • Chat panel: Slide-in right drawer with the research chatbot — available on every page without navigation.
  • Agent status bar: A thin progress bar at the top of the page shows live agent pipeline status during processing (e.g., "PDF Agent ✓ → Embedding ✓ → Granite Synthesis…").
  • Dark mode: Full dark theme with #0d1117 base, toggled via system preference or manual switch.
